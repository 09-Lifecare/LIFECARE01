# LifeCare - Student Health & Life Management Platform

“Stay healthy. Stay organized. Stay prepared. Stay in control.”

## Features

### Core Features

1. **Smart Academic Planner**
   - Class and clinical schedule organizer
   - Task and assignment tracker
   - Deadline reminders
   - Examination countdowns
   - Priority-based to-do lists

2. **Health & Wellness Monitoring**
   - Water intake tracker
   - Sleep monitoring
   - Medication reminders
   - Meal and nutrition logs
   - Physical activity tracking

3. **Mental Health & Stress Support**
   - Mood tracker
   - Stress level check-ins
   - Guided breathing exercises
   - Journaling feature
   - Motivational support

4. **Daily Life Management Tools**
   - Habit tracker
   - Budget and expense tracker
   - Personal notes and checklists
   - Emergency contacts
   - Quick-access resources

5. **Student Support System**
   - Peer support/community features
   - Academic encouragement tools
   - Self-care recommendations
   - Personalized reminders

## Login Information

- **Email**: Enter your email address
- **Password**: Enter any password (for demo purposes)
- **Role**: Select from:
  - Nursing Student
  - Student
  - Professional

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript (ES6+)**: Interactive functionality
- **LocalStorage**: Session and data persistence
